# Module coverage

The supplied Word document is the product requirements reference. The user's explicit React/Vue correction supersedes its Next.js instructions; this implementation uses React with Vite. Only operations supported by the existing backend are exposed.

| Area              | Delivered interface and integration                                                                                                                                                                                                           |
| ----------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Authentication    | Login, password recovery/reset, rotating session restoration, password changes, device sessions, logout/all-session revocation                                                                                                                |
| Workspace         | Project selection, permission-aware menus, search, responsive navigation, themes, offline indicator, notification inbox and personal work                                                                                                     |
| Dashboard         | Real project totals, collection/booking charts, inventory distribution, ageing, approval queue and recent records                                                                                                                             |
| Projects          | Create/edit projects, currency/timezone and business rules; no sample records in the application database                                                                                                                                     |
| Inventory         | Search/filter/sort/paginate, table/cards/matrix, property detail/history, price/status actions and validated CSV import                                                                                                                       |
| CRM/customers     | Lead pipeline and activities, follow-ups/visits/quotations, qualified lead conversion, customer creation/editing, nominees, identity permission checks and ownership history                                                                  |
| Bookings          | Server reservation, payment plan selection/preview, joint ownership checks, approval submission, cleared-down-payment confirmation and booking details                                                                                        |
| Payments/recovery | Record/verify/reverse payments, apply advances, authoritative receipts, installments, recovery cases and promises to pay                                                                                                                      |
| Dealers           | Dealers, allocations, commissions, approvals and settlement actions                                                                                                                                                                           |
| Ownership         | NDCs, transfers, cancellation/refund workflows, possession, inspections and snags                                                                                                                                                             |
| Approvals         | Permission/state-aware review, maker/approver separation, history and sequential approval policy configuration                                                                                                                                |
| Finance           | Accounts, journals and reversals, accounting periods, bank reconciliation, vendors and accounting mappings                                                                                                                                    |
| Documents         | Private uploads/downloads, templates/versions, PDF generation status; platform-specific save/share/print adapters                                                                                                                             |
| Reporting         | Sales, inventory, collections, installments, outstanding, ageing, customer statement, dealers, NDCs, transfers, cancellations, refunds, possession, ledger, cash/bank books, vendor ledger, trial balance, income statement and balance sheet |
| Administration    | Users, roles, project assignments, audit events and settings                                                                                                                                                                                  |
| Windows           | Electron shell, restricted preload bridge, encrypted refresh token, native printing/save dialog and optional update channel                                                                                                                   |
| Mobile            | Capacitor Android/iOS projects, secure token storage, camera upload, QR reference search, network/lifecycle handling, push registration, share/download and Android back handling                                                             |

Lists use server pagination. Matrix and pipeline views clearly apply to the current fetched page. Reports use the backend's bounded report result; exports are generated by its worker. Financial values remain decimal strings until display, and previews use Decimal.js. Backend totals, authorization, approval decisions and transaction outcomes remain authoritative.

Native adapters and project configuration are delivered; hardware camera/scanning, push delivery, real printers, signed updates and store installation require the external tools/devices/accounts listed in `native-release.md`. Dragging cards to change financially meaningful state is intentionally not exposed: explicit reviewed server actions perform those transitions.
